Elements
In Genshin Impact, Elements are special powers that characters use to attack enemies, explore the world, and trigger elemental reactions. There are seven main elements: Anemo, Geo, Electro, Dendro, Hydro, Pyro,and Cryo. Each element has unique abilities and can interact with others to create powerful effects in combat.
